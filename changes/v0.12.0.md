# v0.12.0

## New

- A field can be read only by some: `@security(read [user.admin])` on it.
  The API answers the others the record without the field, and refuses them
  a filter, a sort or the history by it (403, or 401 for nobody). The
  contract says so, and the project's access tests check it. `esquadro check`
  refuses such a field in the search, and rules that name no realm or role.
  See "Fields only some may read" in the documentation's security guide.

## Fixed

- A request its client gave up on, a person who left the page while it
  loaded, was answered and logged as an error of the app, 500 "operation
  failed". It is now 499 `canceled`, logged as an ordinary request.
