# v0.10.2

## Fixed

- A record created by the API without a number or a yes/no field that has
  a default (`stock int default(3)`, `active bool default(true)`,
  `weight decimal default(1.5)`) takes that default, where it took 0 or
  false: refused when the field had a minimum above 0, and stored with
  the wrong value otherwise.
- `security create` and `security invite` send the link to the page of the
  realm's frontend that sets a password (`/admin/reset-password`, a site's
  `/nova-senha`), where they sent it to `/`, which has none; `-redirect`
  still chooses another.
- A panel the app has not built says, besides `task web:build`, where
  `task dev` serves it in development (`http://localhost:5173/admin/`).
