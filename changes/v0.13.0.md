# v0.13.0

## Changed

- The i18n blueprint's `languages` must be language tags, as browsers send
  and read them: `"pt-BR"`, not `"pt_br"`. A tag written another way was
  taken, but matched none of esquadro's translations, so every problem was
  answered in English, and `Content-Language` carried a value browsers do
  not know. `esquadro gen` now refuses it, and says how to write it.

## Added

- The titles of `canceled`, `own_account`, `last_administrator`,
  `already_active` and `already_verified` in pt-BR and es.

## Upgrading

- Write the languages as tags in the i18n blueprint (`languages ["pt-BR"]`).
- If `internal/platform/edge/translations.go` was written for a language
  esquadro did not recognize, it holds that language's titles in English,
  each with `// TODO: translate`, and they take precedence over esquadro's:
  rename its key to the tag, and delete the lines you did not translate.
