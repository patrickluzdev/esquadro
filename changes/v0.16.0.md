# v0.16.0

## Added

- River's own screen of the job queue, served by the API behind sign-in:
  `blueprint jobs { ui "/jobs" }`. It lists the jobs by state, with their
  errors and attempts, and retries, cancels and deletes them. Only the
  roles `ui_access` names may open it (`[user.admin]`; by default, those
  who administer the first realm's accounts). Someone not signed in gets a
  page asking them to sign in first; someone without the role gets a 403.
  The screen needs the security blueprint with a principal, and
  `esquadro check` says so.
- `security.EmbeddedUI`, for a screen of a library the app embeds: it
  checks the session and the roles. A request that changes something
  under the screen's path must come from the API's own address, because
  such pages send no CSRF token. The rest of the API still asks for the
  token. Each such request is logged with who made it.

## Changed

- River is now v0.51.2, with riverui v0.23.0. The upgrade has no new
  migration of River's own; `esquadro gen` raises the version in go.mod.
